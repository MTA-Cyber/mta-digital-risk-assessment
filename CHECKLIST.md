# Checklist de Exposição Digital

## 🔐 Dados pessoais

* [ ] Meu e-mail aparece em vazamentos?
* [ ] Meu telefone está público?
* [ ] Meu CPF/ID já foi exposto?

## 🌐 Presença online

* [ ] Meu nome aparece no Google?
* [ ] Existem conteúdos negativos?
* [ ] Tenho perfis esquecidos?

## 📱 Redes sociais

* [ ] Minhas contas são privadas?
* [ ] Informações sensíveis estão visíveis?
* [ ] Localização exposta em posts?

## ⚖️ Risco jurídico

* [ ] Conteúdos que podem gerar processo?
* [ ] Uso indevido de imagem?
* [ ] Exposição de terceiros?

## 🛡️ Segurança

* [ ] Uso autenticação em 2 fatores?
* [ ] Senhas são seguras?
* [ ] Já sofri tentativa de invasão?
